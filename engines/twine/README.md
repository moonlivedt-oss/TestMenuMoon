# Twine / SugarCube — тест-меню (PoC)

Второй движок кроме Ren'Py. Twine-игра — это один `.html`; переменные истории живут в
`State.variables` (в пассажах `$var`). Меню внедряется в HTML и правит их вживую.

## Файлы
- `tm_menu.js` — **адаптер данных** (`TM_ADAPTER`: как читать/писать `State.variables`).
  Графика/логика меню — в общем `../_shared/tm_menu_core.js` (оверлей Shift+T, вкладки,
  перетаскивание, анимации); инжектор склеивает адаптер+ядро в один `<script>`.
- `inject.py` — внедрить/убрать меню в HTML (идемпотентно, по маркерам).
- `scan.py` — статический скан: перечисляет `$var` из исходников пассажей и по
  `<<set $x to ...>>` подсказывает тип (num/bool/str). Аналог `tm.py curate` для Ren'Py.
- `demo.html` — самодостаточная демо-заглушка SugarCube: открой в браузере и жми Shift+T.

## Как попробовать
Просто открой `demo.html` в браузере → **Shift+T**.

## На реальной игре
```
python inject.py path/to/game.html            # внедрить/обновить меню
python inject.py path/to/game.html --remove    # убрать
```
Затем открыть игру в браузере, **Shift+T**.

## Что уже умеет / чего нет
- вкладка **Переменные**: числа (−/+ ×1/10/100, ввод), булевы, строки;
- вкладка **Сканер**: снимок → изменились/больше/меньше (по числовым переменным);
- вкладка **Экшены**: пресеты (+числа, все флаги true, дамп в консоль) и произвольный JS;
- идемпотентное внедрение и чистое удаление;
- ⏳ только SugarCube (Harlowe не поддержан) — на будущее.

## Скан имён ($var)
```
python scan.py path/to/game.html      # или папка с ним (возьмёт крупнейший *.html)
```
Печатает кандидатов-подсказки: `State.variables.NAME` с типом по `<<set>>`. Значения
всё равно правятся в рантайме — extract/generate не нужны; шаги движка: `scan`,
`deploy`, `uninstall` (см. `tmkit/engines.py`).

## Отличие от Ren'Py-пайплайна
У Twine нет байткода: значения видны в рантайме (меню само перечисляет `State.variables`),
но **имена** можно достать статически из исходников пассажей — это делает `scan`.
Это и есть довод за абстракцию «engine backend»: у движков разный набор шагов.
