Фикстура для скриншотов меню на любом SDK Ren'Py (<папка SDK>/renpy-<v>-sdk).

1. Скопировать папку shot_fixture во временное место (не запускать здесь: Ren'Py пишет .rpyc и log).
2. python tm.py quick <копия>            (движок + tm_ui; на 6.99 вручную убрать " copypaste True",
                                          у копии нет renpy/ рядом, deploy версию не узнает)
3. ZZ_OUT=<папка для png> <sdk>/lib/<py>/python.exe renpy.py <копия> run
   Оверлей zz_shot по таймеру пишет dbg.txt (тема, колбэки), открывает меню, снимает все
   вкладки (и разделы: раскрытая строка «Значений», «Найти переменную», разделы «Теста» и
   «Настроек» — шаги ZZ_SET) и попап диагностики, затем выходит. 800x600 без gui.rpy; для 1280x720 добавить
   init -100 python: config.screen_width = 1280; config.screen_height = 720
Править zz_shot.rpy через редактор, не через bash heredoc (экранирование ломает строки).

Проверка инструментов тестера (2026-10-04): в копии заменить game/zz_shot.rpy на
tools_check/zz_shot.rpy. Сценарий сам доходит до выбора и делает его (focus_down + button_select),
снимает подсказки в трёх режимах спойлеров, HUD со вспышкой, мини-плашку, тост, отметки изменений,
историю выборов, журнал правок, окно ввода, «Где я», сканер «изменилось на» и пишет dbg2.txt
(история, отмена, ввод, сканер, tm_state.json, текст отчёта тестера).

Проверка вкладки «Тест» и прочих новинок (2026-10-06): в копии заменить game/zz_shot.rpy на
qa_check/zz_shot.rpy. Сценарий: авто-прохождение с лимитом, запись и сохранение маршрута,
прохождение по маршруту, подсказки с кодом варианта, «Тест» / «Код» / «Поиск», относительный ввод,
заморозка флага и строки, перенос значений, персонажи, поиск по имени, выражение в HUD, заметка о
баге, сохранение с открытым выбором. Результаты — dbg3.txt (строки STEP N FAIL — ошибки).
Для 6.99 и 7.3.5 старому python нужны PYTHONHOME=<sdk>/lib/windows-i686 и
PYTHONPATH=<sdk>/lib/windows-i686/Lib.
